NeuroSynth achieved improved Task C learning relative to EWC while simultaneously preserving earlier-task knowledge. Final Task C performance reached 9.00\% for NeuroSynth compared to 2.00\% for EWC. Although this difference did not achieve statistical significance ($p = 0.226643$), the observed moderate effect size (Cohen's $d = 0.56$) suggests meaningful performance improvements. Collectively, these results demonstrate that NeuroSynth achieved improved balance between long-term retention and continued adaptation relative to both baseline methods.
